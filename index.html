🧠 ถอดรหัสความคิด: เกมนี้ใช้ "วิทยาการคำนวณ" อย่างไร?

เรียนรู้แนวคิดอัลกอริทึมและการแก้ปัญหาเชิงคำนวณระดับชั้น ป.4

1 การใช้ลำดับคำสั่ง (Sequence)

เกมทำงานตามลำดับ step-by-step: สุ่มผลไม้สร้างตำแหน่ง ➔ เลื่อนวัตถุลงมา ➔ ตรวจการชน ➔ อัปเดตคะแนน

2 การใช้เงื่อนไข (If-Else)

ถ้า (If) ตะกร้าโดนผลไม้ ➔ คะแนนเพิ่มขึ้น
ถ้า (If) ตะกร้าโดนระเบิด ➔ เสีย 1 ชีวิต

3 การใช้ตัวแปร (Variables)

ตัวแปรคือกล่องเก็บข้อมูลในคอมพิวเตอร์ เช่น Score (คะแนน) และ Lives (จำนวนชีวิต)

4 การทำซ้ำ (Loop) & ตรวจสอบการชน

เกมใช้ Loop วาดผลไม้และคำนวณตำแหน่งอย่างต่อเนื่อง 60 ครั้งต่อวินาที (FPS) พร้อมตรวจสอบการซ้อนทับกัน

🍎 แอปเปิล = +10 🍊 ส้ม = +10 🍌 กล้วย = +10 🍉 แตงโม = +15 ⭐ ดาวพิเศษ = +20 💣 ระเบิด = -1 ชีวิต

แนวคิดวิทยาการคำนวณ (ป.4)

วิเคราะห์อัลกอริทึมของเกมจับผลไม้

ผังงานการทำงานของเกม (Flowchart Logic)

  1. เริ่มเกม ➔ กำหนด Score = 0, Lives = 3
  2. สุ่มวัตถุ (ผลไม้ / ระเบิด) ตกจากด้านบน
  3. ผู้เล่นกดปุ่ม ซ้าย / ขวา เพื่อย้ายตะกร้า
  4. ถ้า (วัตถุชนตะกร้า) ➔
    • กรณีผลไม้: คะแนนเพิ่มขึ้น (+10, +15, +20)
    • กรณีระเบิด: ชีวิตลดลง (-1)
  5. ถ้า (คะแนนเพิ่มทุก 50 คะแนน) ➔ เพิ่มระดับความยาก (Speed Up)
  6. ถ้า (ชีวิต == 0) ➔ แสดงหน้าจอ Game Over!
📌 ตัวแปรสำคัญ (Variables)
  • • score: เก็บค่าคะแนนสะสม
  • • lives: เก็บจำนวนชีวิตที่เหลือ
  • • level: เก็ประดับความยาก
  • • speed: ความเร็วในการตก
